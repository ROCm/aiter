Task1：OPUS A16W16 Split-K workspace To Torch

最终代码状态 · 更新日期：2026-08-13 · 本页比较原始基线与当前最终版本，不记录中间版本。

Task1 功能与回归验收完成
所有权workspace 是普通 Torch Tensor，由当前调用或调用方持有。
分配按最终 kid、split-K、batch、M、N 和该 kid 声明的 workspace dtype 规划。
启动Tensor 指针直接传入 A16 family launcher 和 C++ exact-kid 表。
选核显式 kid 直达 exact public；未显式指定时由上层依次查 tuned、heuristic 和 PyTorch fallback。

1. 最终验收结论

  • Split-K workspace 的创建、复用和生命周期均由 Torch 侧管理。
  • 调用方可以传入 workspace；未传入时按当前调用创建。
  • 非 workspace kid 不创建 workspace，也拒绝多余的 caller workspace。
  • workspace Tensor 与当前 stream 正常协作，可在 CUDA Graph capture 前准备并稳定 replay。

2. 原本流程与当前流程

改造前

1. 调用入口 调用方进入 gemm_op_a16w16.py::gemm_a16w16_opus(A, B, ...)。
↓
2. Python 准备 校验并 reshape 输入，由 wrapper 创建 Y。
↓
3. 选核分支
调用时传入 kernelId opus_gemm_a16w16_tune(..., kernelId, splitK)
调用时未传 kernelId common.py::lookup_tuned()
命中 → tune API
miss → _opus_gemm_bf16_dispatch() → C++ generic opus_gemm() → generated lookup / C++ heuristic
↓
4. 架构 launcher 进入当前 arch 的 generated A16 launcher。
↓
5. C++ 获取 workspace Split-K launcher 调用 opus_splitk_ws_get(stream, allow_create)；per-stream registry 查找或扩容 workspace handle。Graph capture 前调用 opus_gemm_workspace_init() 预建当前 stream handle。
↓
6. GPU 执行 workspace kid：main kernel 写 C++ 内部 buffer → reducer → Y；non-workspace kid：直接写 Y。

当前

1. 调用方解析最终 kid
显式最终 kid 直接进入 aiter/ops/opus/__init__.py::opus_gemm(kid=...)。
未显式指定 tuned_gemm.py::gemm_a16w16() → get_GEMM_A16W16_config()
tuned CSV → per-arch private heuristic → PyTorch fallback；得到 OPUS kid 后进入统一 public。
↓
2. 唯一 public aiter/ops/opus/__init__.py::opus_gemm() 使用最终 kid 进入 A16 private family。
↓
3. A16 指定-kid 路径 gemm_op_a16w16.py::_launch_a16w16() → _explicit_a16w16_launch()。
↓
4. Torch workspace 根据最终 kid 计算 workspace；复用 caller Tensor，或执行 torch.empty() 创建本次调用的 Tensor。
↓
5. OPUS 模块内 C 启动接口 首次调用沿用 pybind 完成 JIT 加载；后续由 _opus_gemm_a16w16_launch_ctypes_raw() 调用同一模块中的 C 函数，并传入 workspace pointer 和当前 stream。
↓
6. C++ kid → launcher 映射表 gfx*/opus_gemm_arch_gfx*.cuh 用最终 kid 取得唯一 launcher；这里不再选核或替换 kid。
↓
7. GPU 执行 workspace kid：main kernel 写 Torch Tensor → reducer → Y；non-workspace kid：直接写 Y。
