Kernel ABI修改结构

旧ABI
  opus_splitk_ws_handle*
      └─ device端二次解引用 -> ptr

新ABI
  main kargs: void* ptr_ws
  reduce arg: const void* ws_ptr
      └─ direct pointer

traits
├─ D_ACC   累加类型
├─ D_WS    workspace读写类型
└─ D_OUT   最终输出类型

pipeline
└─ ptr_ws -> D_WS*

reduce
└─ ws_ptr -> const D_WS*

gfx942保留direct-pointer uniform helper：

ptr_ws
  -> opus_gfx942_uniform_ws_ptr()
  -> 64-bit readfirstlane uniform化
  -> D_WS*
