# Domain Docs

Before exploring, read root `CONTEXT.md` and relevant ADRs under `docs/adr/`.
If either is absent, proceed silently.

This repository uses a single-context layout:

```text
/
├── CONTEXT.md
└── docs/adr/
```

Use the glossary vocabulary from `CONTEXT.md`. Do not replace terms with
synonyms that the glossary explicitly avoids.

If work contradicts an existing ADR, surface the conflict explicitly rather
than silently overriding it.
