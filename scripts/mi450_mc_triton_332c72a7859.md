## Notes

- All benchmarks ran on a single GPU (GPU 0) with no explicit GPU isolation or frequency locking.
- The `gemm_warp_pipeline_cdna5.py` benchmark ships with the Gluon compiler test suite, not the aiter repo.
- MoE benchmarks report CUDA-graph-captured timings.
- Norm/fusion and quant benchmarks report effective memory bandwidth (GB/s) rather than TFLOPS.
- Time (ms) values for GEMM are computed as `2×M×N×K / (TFLOPS × 1e9)`.
