# Selected C8 regions and integration contract

These are working, benchmarked single-launch ablations, not an installed serving revision. Existing /work/batch-full and /app/ATOM were deliberately not overwritten by tuning candidates.

- attention_paged.py: attention_paged consumes the real global page pool, flat global indices, M+1 indptr, current per-row KV and real current-token destination rows. Pages is the actual allocation row count. It skips empty splits, interleaves rows before head/split, and uses eight splits. Scratch Max/Sum/Acc must use eight-split strides (existing64-split allocation is large enough). Replace the old compact-cache staging and attention call together; only retain cosine/sine lookup. Preserve invalid-batch cache/state guards and final KV scatter. Check active/empty ragged rows before rollout. aiter_paged.py includes runtime WRITE_SLOT support.
- routing_batch.py: drop-in route_body ABI for power-of-two M1/2/4/8. Scope tested: learned routing including bias/ties. Requires later consumer barrier already present in ffn_body. Do not substitute for hash routing.
- moe_multitoken_prototype.py: selected BN256/BK512/two-buffer stage with original ABI. moe_task_stage.py supplies copied AITER-derived kernels. Only active map entries are scheduled. phase uses existing coherent device-load poll helper.
- mhc_native_region.py + mhc_native_inline.py: native packed-weight fused post/pre. Inputs use native shuffled residual layout; outputs post/comb are separate contiguous arrays, not Mix[M,24]. Wire or pack these into existing Mix ABI, and preserve FP32 residual information if needed by subsequent stages. Producer and reducer use original AITER layouts and warp specialization. The dedicated counter must not alias the normal256-CTA phase counter; only64 producers participate. Full-kernel warp specialization/resource occupancy must be checked before launching.
- compress_defs.py + compressor_batch.py: dedicated producer-count barrier; HCA requires Work[8,4,3,512] FP32. HCA parallel ring pooling currently assumes state128 and boundary-aligned R128. Ordinary token still performs state write. No production call may pass Work for indexer/ratio4. Existing MC plans with8-field stride must be adapted from this fixture's separate4-field plan tensors. Preserve invalid-row masks and slot migration handling.

Next validation: wire region scratch/ABIs into a separate full-layer candidate; compile and check VGPR/LDS/spills before persistent launch; dual-forward per-stage check; graph-padded requests; then model-wide accuracy and E2E clients twice/server once.
