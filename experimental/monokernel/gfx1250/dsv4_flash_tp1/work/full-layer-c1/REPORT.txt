Flash C1 full-layer isolated prototype — completed single-launch experiment

This is one complete uncompressed Flash layer (layer0), including mHC, QKV and
output projections, Q/K norms+RoPE, sliding-window cache write, attention with
sink, inverse RoPE/grouped LoRA, hash routing, shared expert, six routed FP4
experts, and final mHC residual. Profiler proves ONE kernel named full_layer.

It is NOT whole-model serving. The current prototype does not cover ratio4/
ratio128 compression and indexer layers, learned routing, ATOM paged-cache
metadata, or Pro TP4. It uses real checkpoint weights/embedding with controlled
synthetic historical cache and rotary-angle inputs. No TPOT/TTFT/tok/s or GSM8K.

Why the initial approaches did not win:
- Earlier C1 mHC+QKV:12.54us fused vs10.71us separate. Resident-grid handoff,
  synchronization and decomposition costs can exceed one saved launch.
- Earlier routed-MoE serving ablation:5.825129ms vs5.731084ms library MoE.
  Isolated MoE improved in some tests but serving did not; stream overlap and
  critical-path changes remain hypotheses, not a measured causal decomposition.
- This full-layer prototype: broad synchronization generated32 global writebacks
  and96 global invalidations. Replacing that protocol improved latency but still
  loses to its own split control. Current vector matvecs are not tuned WMMA;
  a slow correctness-first implementation does not disprove full-layer fusion.
