Set ATOM_DSV4_HYBRID_ATTN=0 for the prior-hybrid control. All other flags remain
identical. Start a new server process when changing flags, so GPU graphs are
captured with the selected implementation. CHECK performs exact live projection
comparisons during uncaptured warmup; it does not time additional reference
kernels during steady captured serving.

Benchmarks (separate shell, same container, from /work)

This profiles concurrency 64 and 128, then runs a full workload warmup and a
reported repetition for each. It also saves deterministic concurrent completions.

tokens, 4*C requests, seed 0, ignore EOS, no prefix caching.
Avoid concurrent GPU workloads. Trace analysis can run after measurements:
  python /work/round2/analyze_serving.py my_candidate

Experiments
attention_tune.json: initial tile, LDS, multicast and prefetch sweep. Compilation
failures are retained in the log and JSON; these configurations were not selected.
attention_joint.json: joint pipeline/cluster tuning (also retains failed trials).
attention_prefetch.json: corrected prefetch lookahead sweep.
attention_finalists.json: rotating-weight, alternating baseline/candidate timings.
selected_attention.json: selected measured configurations before deployment.
candidate/dsv4_attention_configs.json: actual serving dispatch table.

The optional aiter-prefetch-experiment.patch is NOT installed for serving. Apply
it only in an experimental checkout on top of the first-round AITER state before
running the prefetch tuning scripts. It adds L2_PREFETCH_DISTANCE to existing
configuration files and launches. The installed serving configuration uses no
added prefetch, semaphore, or collective override.

The semaphore probes are isolated experiments, not production implementations.
Only the acq_rel reference and explicitly drained scoped-asm versions satisfy
the tested ordering checks. The .cg/relaxed version is not accepted as correct;
the first explicit-asm attempt failed correctness. Keep those failures when
reviewing the experiment. Do not reuse the probes as a general synchronization
library or apply device scope to peer-GPU memory.

Validation details: serve_validation.sh enables eager execution. Set
ATOM_DSV4_HYBRID_ATTN_CHECK_LIMIT=100000 and ATOM_DSV4_HYBRID_CHECK=1, then run
validate_real_batches.py. This is not a timed serving run. Production default
check limit remains2. See real_validation_summary.json for logged lower bounds.
The final successful intra-device semaphore experiment is
semaphore_probe_scoped_buffer.py; its scalar-ASM predecessor failed and is not
an alternative implementation. All semaphore experiments remain unintegrated.
