## Repeatability

GPU2 raw run medians (GEMM1 / GEMM2, us):

- Gather baseline: 537.00 /593.76; 536.76 /595.99.
- GEMM1 TDM only: 512.77 /580.81; 531.17 /598.49.
- GEMM1+GEMM2 TDM: 531.49 /586.59; 532.23 /586.49.

The full TDM variant improves the all-rank average by only0.80% for GEMM1
and0.68% for GEMM2. On GPU2 the respective reductions are0.94% and1.40%.
The larger first-run GEMM1-only gain did not fully repeat. This is a limited
kernel-latency result, not a robust large speedup. Keep both features opt-in.
GEMM2 ordinary-store is confirmed by the `_eplinear` symbol in the JSON.

The standalone GEMM1-only row still runs the original gather-store GEMM2;
its GEMM2 variation is not evidence of a GEMM2 code improvement. Changing
landing capacity also shifts arena addresses and changes pre-GEMM traffic.
These whole-graph results do not isolate transfer-instruction latency alone.

## Correctness

Both implementations pass257 and16384 tokens/rank, EP4, six changing-input
graph replays per size: random routing, hot/empty experts, disjoint source
ownership and unequal tails. The original push output is the reference;
exact payload/scales/weights, route coverage, M256 source uniqueness and
live-row metadata are checked. No reboot occurred during these passing runs.
Normal-routing correctness is covered; the performance table is balanced only.
