## Protocol changes (each with its test seam / gate)
1. **Per-comm ERR word** (`args.err`, u32 at the global page base; layout of the card): `set_err` does a system CAS 0 -> `reason | origin<<8 | kind(2)<<10`; the winner writes DIAG (u64[8] at +64: expected tag, seen tag, aux, plan code, epoch, rank) and does a relaxed system CAS 0 -> `code | propagated(1<<12)` into the 3 peers' ERR words (`args.gpeers->err[r]`, may be null). The old poison word in C is a diagnostic mirror only: no decision reads it. Seam: existing `LG_X_FORCE_TIMEOUT_G0/G1`, forced W2 timeout, forced config mismatch => ERR set on the origin rank, propagated flag on the peers, mirror = reason.
2. **ERR at entry + in every poll**: poster returns at entry (no credit, wait, put, arrival) when ERR != 0; `r12_poll_u32_ge/u64_ge` and the W2 spin test the target first, then ERR each iteration (-1 = ERR seen: leave without setting again; drain the peer queue if puts were issued); an explicit ERR check sits before each put and before the arrival. Gate: pre-set ERR from the host, launch, `LG_STAMPS` poll counters = 0, `LG_DEBUG_POSTCOUNT` posts = 0, no credit/arrival written; ERR set mid-launch (host write or propagation) => waits end within one poll iteration, not the budget (G4).
3. **ctag/atag (step tags)**: `E = (STEP << 32) | call_id` (STEP read once per kernel, agent-scope relaxed; ATOM''s `add_` is earlier in the stream). The poster lane stores `ctag[rank]@peer = E` (relaxed system store) immediately before its credit release (`st_u64_rel_x` = fence(release) -> vmcnt(0) -> store), and `atag[rank]@peer = E` before its arrival release: the same thread, program order before its own fence (D-2). Consumers: after the credit acquire the poster reads `ctag[peer]` and, if != E, `set_err(TAG_CREDIT 0x31)` and returns BEFORE any put; quiet_ready after `arrival == e` + acquire reads `atag[d]` and, if != E, `set_err(TAG_ARRIVAL 0x32)`. Seams: `LG_X_TEST_BAD_CTAG` / `LG_X_TEST_BAD_ATAG` (peer slot 0 presents E^1: the receiver MUST set 0x31 / 0x32, ERR propagates); `LG_X_TEST_CTAG_AFTER_RELEASE` / `LG_X_TEST_ATAG_AFTER_RELEASE` with `LG_X_TEST_TAG_DELAY_ITERS` (tag store after the release: stale-tag mismatches MUST appear = negative control of the store-before-release rule; clean build: zero mismatches over 1e4 replays with a source-delay).
4. **quiet_ready under ERR**: W2 skipped when ERR != 0 at entry (or when ERR appears during W2); the DONE/STATE reset ALWAYS runs (item blocks keep incrementing gdone without a poster; skipping it would trip DUP_CHUNK next launch); the epoch advances only if ERR == 0. Gate: ERR launch followed by `reset()` => next epoch clean, no DUP_CHUNK.
5. **`lg_nan_fill_v1(const uint32_t* err, void* R, uint64_t bytes)`** (alternative B, no helper-WG spin): separate node launched after quiet_ready by `lg_launch_v2` (the runtime must NOT add its own); grid `LG_NAN_FILL_WGS (256) x 256` compile-time (no dispatch-packet read); exits at once when `*err == 0`; else grid-stride writes BF16 0x7FC0 over `8*M*F + LG_R_PAD_BYTES` bytes of R (reuse pad included). Best effort: no drain of incoming puts (D-3, I3). Gate: ERR set => the golden receiver reads NaN rows; ERR clear => R bytes untouched (byte-equal to r11) and the node costs one tiny launch (G2).
6. **Config guard**: additional terms `err != nullptr`, `step != nullptr`, `pad == 0`; abi_version = 4. The host launcher refuses a launch without an attached page (-110) and a `call_id` >= 2^31 (-104).
7. **F0 only**: `static_assert(!LG_R8_FOLD)` (device) and `#error` (host): the folded poster has no tag/ERR/fill logic.

## Host API (for aiter-integrator; ABI >= 4 only)
`lg_gpage_attach_v1(h, err_dev_ptr, step_dev_ptr, gpeers_dev_ptr_or_null)` once after `lg_attach_v1`; `lg_launch_v2(..., half_first, call_id, stream)` = GEMM + quiet_ready + fill (capturable, no sync/alloc); `lg_abi_info_v1(out8)` = {abi, sizeof(args), ERR/STEP/DIAG offsets, ctag/atag offsets, sizeof(LgGfPeers)}. `lg_launch_v1` and `lg_poison_v1` are compiled out for ABI >= 4 (per-plan poison hooks are removed by the card); `lg_report_v1` stays (diagnostic mirror + counters). `lg_attach_v1` resolves `lg_nan_fill_v1` (diag stage 7 if missing). The window init (`lg_init_control_v1`) zeroes the whole C image, so ctag/atag/mirror restart at 0 on `reset()`.
Assumption to confirm with A1: `LgGfPeers` = `{uint32_t* err[4]}` indexed by world rank (own entry ignored), device-resident, pointers from `ccoGetPeerPtr`; the global page is `err` at +0, `step` at +8, DIAG at +64.

## Deviations / risks (stated)
- The fill kernel reads `*err` with a SYSTEM-scope relaxed load (card says device scope): propagated ERR arrives through the fabric.
- Everything is uncompiled; `lg_nan_fill_v1` relies on `opus::block_id_x()/thread_id_x()` and an `ext_vector_type` store in the RTC kernel TU; entry-table order changed (fnan appended after fdrain).
- The kernels still use `wait_budget` unchanged (D-6: sticky ERR makes later launches skip waits; first-launch budget residual stated by the card).
- r11 is not modified; the `r11 -> r12` swap in the Python runtime/prebuild entries belongs to aiter-integrator.
