## Protocol changes (each with its test seam / gate)
1. **Per-comm ERR word** (`args.err`, u32 at the global page base; layout of the card): `set_err` does a system CAS 0 -> `reason | origin<<8 | kind(2)<<10`; the winner writes DIAG (u64[8] at +64: expected tag, seen tag, aux, plan code, epoch, rank) and does a relaxed system CAS 0 -> `code | propagated(1<<12)` into the 3 peers' ERR words (`args.gpeers->err[r]`, may be null). The old poison word in C is a diagnostic mirror only: no decision reads it. Seam: existing `LG_X_FORCE_TIMEOUT_G0/G1`, forced W2 timeout, forced config mismatch => ERR set on the origin rank, propagated flag on the peers, mirror = reason.
2. **ERR at entry + in every poll**: poster returns at entry (no credit, wait, put, arrival) when ERR != 0; `r12_poll_u32_ge/u64_ge` and the W2 spin test the target first, then ERR each iteration (-1 = ERR seen: leave without setting again; drain the peer queue if puts were issued); an explicit ERR check sits before each put and before the arrival. Gate: pre-set ERR from the host, launch, `LG_STAMPS` poll counters = 0, `LG_DEBUG_POSTCOUNT` posts = 0, no credit/arrival written; ERR set mid-launch (host write or propagation) => waits end within one poll iteration, not the budget (G4).
3. **ctag/atag (step tags)**: `E = (STEP << 32) | call_id` (STEP read once per kernel, agent-scope relaxed; ATOM''s `add_` is earlier in the stream). The poster lane stores `ctag[rank]@peer = E` (relaxed system store) immediately before its credit release (`st_u64_rel_x` = fence(release) -> vmcnt(0) -> store), and `atag[rank]@peer = E` before its arrival release: the same thread, program order before its own fence (D-2). Consumers: after the credit acquire the poster reads `ctag[peer]` and, if != E, `set_err(TAG_CREDIT 0x31)` and returns BEFORE any put; quiet_ready after `arrival == e` + acquire reads `atag[d]` and, if != E, `set_err(TAG_ARRIVAL 0x32)`. Seams: `LG_X_TEST_BAD_CTAG` / `LG_X_TEST_BAD_ATAG` (peer slot 0 presents E^1: the receiver MUST set 0x31 / 0x32, ERR propagates); `LG_X_TEST_CTAG_AFTER_RELEASE` / `LG_X_TEST_ATAG_AFTER_RELEASE` with `LG_X_TEST_TAG_DELAY_ITERS` (tag store after the release: stale-tag mismatches MUST appear = negative control of the store-before-release rule; clean build: zero mismatches over 1e4 replays with a source-delay).
4. **quiet_ready under ERR**: W2 skipped when ERR != 0 at entry (or when ERR appears during W2); the DONE/STATE reset ALWAYS runs (item blocks keep incrementing gdone without a poster; skipping it would trip DUP_CHUNK next launch); the epoch advances only if ERR == 0. Gate: ERR launch followed by `reset()` => next epoch clean, no DUP_CHUNK.
5. **NaN fill** (superseded by r12c below: the separate `lg_nan_fill_v1` node no longer exists): grid-stride BF16 0x7FC0 over `8*M*F + LG_R_PAD_BYTES` bytes of R (reuse pad included), best effort, no drain of incoming puts (D-3, I3). Gate: ERR set => the golden receiver reads NaN rows; ERR clear => R bytes untouched (byte-equal to r11) and the node costs one tiny launch (G2).
6. **Config guard**: additional terms `err != nullptr`, `step != nullptr`, `pad == 0`; abi_version = 4. The host launcher refuses a launch without an attached page (-110) and a `call_id` >= 2^31 (-104).
7. **F0 only**: `static_assert(!LG_R8_FOLD)` (device) and `#error` (host): the folded poster has no tag/ERR/fill logic.

## Host API (for aiter-integrator; ABI >= 4 only)
`lg_gpage_attach_v1(h, err_dev_ptr, step_dev_ptr, gpeers_dev_ptr_or_null)` once after `lg_attach_v1`; `lg_launch_v2(..., half_first, call_id, stream)` = GEMM + quiet_ready + fill (capturable, no sync/alloc); `lg_abi_info_v1(out8)` = {abi, sizeof(args), ERR/STEP/DIAG offsets, ctag/atag offsets, sizeof(LgGfPeers)}. `lg_launch_v1` and `lg_poison_v1` are compiled out for ABI >= 4 (per-plan poison hooks are removed by the card); `lg_report_v1` stays (diagnostic mirror + counters). `lg_attach_v1` resolves `lg_nan_fill_v1` (diag stage 7 if missing). The window init (`lg_init_control_v1`) zeroes the whole C image, so ctag/atag/mirror restart at 0 on `reset()`.
Assumption to confirm with A1: `LgGfPeers` = `{uint32_t* err[4]}` indexed by world rank (own entry ignored), device-resident, pointers from `ccoGetPeerPtr`; the global page is `err` at +0, `step` at +8, DIAG at +64.

## Deviations / risks (stated)
- The fill kernel reads `*err` with a SYSTEM-scope relaxed load (card says device scope): propagated ERR arrives through the fabric.
- Everything is uncompiled; `lg_nan_fill_v1` relies on `opus::block_id_x()/thread_id_x()` and an `ext_vector_type` store in the RTC kernel TU; entry-table order changed (fnan appended after fdrain).
- The kernels still use `wait_budget` unchanged (D-6: sticky ERR makes later launches skip waits; first-launch budget residual stated by the card).
- r11 is not modified; the `r11 -> r12` swap in the Python runtime/prebuild entries belongs to aiter-integrator.

## r12b (overhead round F6, records/architecture/stage3/R12-small-overhead.md 5070dd81…): +7.5…8.6 us vs r11 at T8192
Two compile-time knobs, defaults ON, `=0` restores the r12 behaviour for the A/B (build_device.sh passes them, together with the test seams that r12 forgot to plumb: LG_X_TEST_BAD_CTAG/BAD_ATAG/CTAG_AFTER_RELEASE/ATAG_AFTER_RELEASE/TAG_DELAY_ITERS). All R12 semantics are kept (sticky ERR, tags, NaN fill node).
- **LG_TAG_EARLY=1 (F1/F6).** The ARRIVAL tag is stored right after the credit-tag check (first put group), i.e. in the batch of the first put, by the lane that later releases the arrival; at the arrival release (after quietQueue) it has long retired, so `fence(release) -> vmcnt(0)` has no outstanding remote store: the atag store RTT leaves the critical tail (arrival -> peer W2 -> receiver). Safety: the store happens only after the peer''s credit e is observed; the peer issues credit e at the start of its epoch e, after its quiet_ready e-1, which already read `atag[us]` => no WAR with the consumer''s read (the same chain as r12). Ordering: tag store -> (program order) -> puts/quiet -> the lane''s fence(release) -> arrival RMW. **The credit tag is NOT moved**: it is the poster''s first action (nothing earlier to batch with, and storing it in the previous launch is impossible because E = (STEP<<32)|call_id is unknown); its RTT sits before the credit release but is hidden behind GEMM group 0 (>= ~45 us), off the critical path. So F1 recovers only the atag part on the large path. Seams: `LG_X_TEST_ATAG_AFTER_RELEASE` (late store after the release; still disables the early store, mismatches MUST appear) and `LG_X_TEST_BAD_ATAG` (value E^1 in both variants; 0x32 MUST be raised).
- **LG_POLL_BATCH=1 (F2).** `r12_poll_u32_ge/u64_ge` (gdone and credit waits) and the quiet_ready W2 spin load the target word and the ERR word back-to-back each iteration (one wait, one RTT) before comparing; the condition is still tested before ERR. `=2`: ERR only every 8th iteration; `=0`: r12 (ERR loaded after the compare). ERR is a liveness signal: a late sight only delays the sticky skip (bounded). Evidence check: two `global_load ... sc0 sc1` before one `s_waitcnt` per iteration in the poll loops (the compiler could otherwise serialize them).
- Gates unchanged (G4/G10): the A/B for timing is (a) r12 (`LG_TAG_EARLY=0 LG_POLL_BATCH=0`), (b) TAG_EARLY only, (c) POLL_BATCH only, (d) both; falsifier: (d) not within ~1-2 us of r11 + the NaN-fill node cost => an unidentified source remains (ISA of the fill node, entry ERR/STEP loads). Forecast (inference, from the study): -3…-6 us of the +7.5…8.6; my own estimate for the large path is the lower half because the credit tag stays and the fill node (~0.4-3 us) stays.
- Not changed: shared host driver, ABI struct, F0-only rule.

## r12c (overhead-r2 A1, records/architecture/stage3/R12-overhead-r2.md 740f6b78…): the separate `lg_nan_fill_v1` graph node is removed
The fill is folded into `quiet_ready`, which now runs `LG_QR_WGS` workgroups x 256 threads (default 64; `LG_QR_WGS=1` = A1'': single WG, identical to r11's healthy path). `lg_launch_v2` launches NO separate fill node: the graph keeps r11's 3 nodes per call (G-A1a).
- **Every WG reads ERR once at entry.** WG >= 1: ERR == 0 => exit at once (no waits, no flags, nothing else); ERR != 0 => grid-stride fill of ITS share of R (+ the reuse pad) with BF16 NaN (`r12_fill_nan(a, wg, LG_QR_WGS)`, 16 B stores). WG0: unchanged W2/reset/epoch role (W2 skipped when ERR was set at its entry; the DONE/STATE reset always runs; the epoch advances only if ERR is clear at the end). Then WG0 decides the fill from ONE thread-0 read broadcast through LDS: ERR was set at WG0's entry => fill its share (the 63 helpers fill theirs: the usual sticky case, fast); ERR clear at WG0's entry but set at the end (W2 timeout, tag mismatch, mismatch, or a propagated ERR that arrived while WG0 spun) => the helpers exited at their entry, so **WG0 fills ALL of R alone** (256 threads; inference ~1-2 ms for 38 MB at M2048, only in that one launch, which is in the abort window anyway).
- No inter-WG wait or flag exists, so the co-residency / forward-progress objection (review D-3a) does not apply; a CU-starved dispatch only delays the helper WGs, never blocks.
- **Residual (stated):** if ERR is set exactly during dispatch so that WG0 reads it set while some helper WG read it clear and exited, that helper''s share is left un-filled (stale). Same class as the late-put race of D-3b (best effort); the abort covers the clients (R3).
- Seams: all R12 seams unchanged (`LG_X_FORCE_TIMEOUT_G0/G1`, `LG_X_TEST_*` tag seams): G4-ext re-run: ERR set before the launch => R all-NaN after quiet_ready (64-WG fill); ERR set by WG0 in-launch (forced W2 timeout, `LG_X_TEST_BAD_ATAG`, peer tag mismatch) => R all-NaN (WG0 fill alone); a late put after the fill => the request is still aborted; starvation variant: a concurrent stream occupying the CUs => no hang.
- Removed: `lg_nan_fill_v1` entry and stub, `LG_ENTRY_NAN_FILL`, `LG_NAN_FILL_WGS`, `LgCommCtx::fnan`, the fill launch, and the `lg_nan_fill_v1` lookup in the shared `lg_fusion_driver.cpp` (it now resolves only the entries of r11). New: `LG_QR_WGS` (ABI header, build_device.sh). Static check to refresh (aiter-integrator): `LARGE_SRC_SHA["r12"]` in `variants_large.py` still pins the r12b manifest (93bfbcba…); the Python comments that mention the fill node in `lg_launch_v2`.
- Forecast (inference from the study): -3.4…-4.7 us (the node) at +<= 0.5 us for the 63 extra WGs (dispatch only); keep A1'' (`LG_QR_WGS=1`) if the 63 WGs cost anything measurable. Gates: G-A1a node count = 3; G-A1b formal C within noise of r11 (A1'') or <= +0.3 us (A1).

## r12d (small fix per aiter-integrator) + a BUG FIX in r12c
- **BUG FIX (my error in 088c80c8):** in `r6_quiet_ready` the ERR read at entry was named `err0 = err_clear(a)` (TRUE when ERR is clear) but WG0''s fill decision was written `s_fill = err0 ? 1 : ...`, i.e. a CLEAN launch would have filled R with NaN (share fill). Fixed: the variable is now `clr0`, the decision is `s_fill = !clr0 ? 1 (ERR set at entry: fill my share) : (clear_now ? 0 : 2 (ERR appeared: fill ALL of R alone))`. Any r12c build from 088c80c8 must be discarded.
- `host/build_host.sh` now passes `-DLG_QR_WGS=${LG_QR_WGS:-64}` (matching `build_device.sh`).
- **Host/device LG_QR_WGS mismatch is refused:** `LgCommArgsV4.qr_wgs` (the former pad word @348) carries the HOST build''s LG_QR_WGS; the GEMM entry guard (`args.qr_wgs != LG_QR_WGS` => CONFIG poison, uniform return) and quiet_ready WG0 (`set_err(CONFIG, device value, host value)`; W2 skipped, no epoch advance, WG0 fills all of R alone) enforce it at launch, fail-closed. A host cannot see the device image''s constant, so an attach-time check by the host alone is impossible; the runtime can however compare the new `lg_abi_info_v2(out9)` word `out[8] = LG_QR_WGS (host build)` with the value it built the image with and refuse at attach.
- Static checks / pins for aiter-integrator: refresh `LARGE_SRC_SHA["r12"]`; extend the abi-info check to `lg_abi_info_v2`.
