# small/r19: R12 kernarg v3 + per-launch tags + sticky ERR (derived from small/r18)

Status: SOURCE ONLY (uncompiled, no GPU). Derived from r18 (r18 untouched). Design: `records/architecture/stage3/R12-design-card-r2.md` (R2.2 D-2, D2.3, D2.5). This directory is **path A's only r19**, and the **r19b diff** of path B (apply `DIFF-r18-r19.patch` to r17 for r19a; the identical-diff check is `diff r17->r19a == diff r18->r19b`).

## What changed vs r18
- **ABI** `interface/sm_abi_v3.h` (was sm_abi_v2.h): `SM_ABI_VERSION 3`; `SmRanArgsV3` 64 B by value `{blk, Ascale, positions, slot_mapping, err, step, M, rank, t_valid, call_id}` (field order = the aiter stub, small_rt.py `SmRanArgsV3`); `SmDev` stays 384 B (`kc_sh_unused` -> `const SmGfPeers* gpeers`; Ascale/positions/slot_mapping/index_slot_mapping are written nullptr by the host and never read by the kernel); `SM_C_POISON` retired; `SM_C_TAG(par,src) = SM_C_FLAGS + 64 + 8*(par*4+src)` (bytes 320-383 of the destination ctl window).
- **ERR word** (shared with the large path): `reason[7:0] | origin_rank[9:8] | kind[11:10] (1 small) | propagated[12]`, first CAS wins, all reasons < 0x100: timeout 0x20, **overshoot 0x21 (r18's `0x20|0x100` collided with origin bit 8)**, tag mismatch 0x30, contract 0x40/0x41/0x42. `set_err` = CAS(ERR 0->code) + DIAG[0..3] + relaxed CAS(code|PROPAGATED) into the peers' ERR via `SmDev::gpeers` (cold path).
- **Kernel** `sm_ran_v3(SmRanArgsV3)` (body kept as `ran_body(const SmDev* __restrict__, const SmRanArgsV3&)`, so the SmDev loads stay invariant scalar loads):
  - per-launch inputs: `ka.Ascale`; `pre_a` takes positions/slot_mapping/t_valid and pads rows `t >= t_valid` in-kernel (pos 0, slot -1, loads not issued); the index slot is `slot_mapping`.
  - entry round: the poison word load became `ez = ld_rlx32(ka.err)` (system scope; nonzero => NANMODE) and `E = (STEP << 32) | call_id` (same single round trip).
  - **D-2 tags**: `release_tagged()` = the releasing thread's system-scope relaxed tag store `tag[par][rank]@d = E`, then fence(release) -> vmcnt(0) -> RMW, at all 5 release sites (IK x3 destinations, PUSH8 first dest tid 0, PUSH8 second dest tid 256, legacy push, test-only ADD_BEFORE_RETIRE).
  - **B WGs**: `poll_range64` also reads `*err` each iteration (set ERR => return false, no second set_err), overshoot -> set_err(0x21), timeout -> set_err(0x20); after the acquire the tag is loaded in the same batch as the Rx loads (system-scope load; bypass-equivalent) and compared after the batch; mismatch -> set_err(0x30) + that wave's rows become NaN.
  - **NANMODE** (the r18 silent skip is gone): push/IK/PUSH8 WGs: no push, no release; self WG: NaN input to head_row; IK self fusion: NaN `vv`; B WGs: skip the poll, `x = NaN`, normal head_row => NaN q/k/v/index_q and NaN-derived cache bytes (I4). `ep_r` is stored only when ok. The deferred end-of-kernel CAS is `set_err` with the 0x40-0x42 reasons.
  - `SM_NO_CREDIT` must be 1 (`#error` otherwise: the credit slow path used the retired poison word). All r17/r18 shape switches (PUSH8, HALVES, B_ROWSPLIT, RX_BYPASS, REUSE_NO_IDX, NT, ...) are kept unchanged.
  - test seams (default 0): `SM_TEST_DELAY_RELEASE=<n>` (delayed source before tag store + release; G10a), `SM_TEST_TAG_AFTER_RELEASE=<n>` (RMW first, sleep, tag store after; G10b: 0x30 MUST appear).
- **GEMM** `device/sk_gemm_fp8.cu`: only the include rename.
- **Host** `host/driver_sm.cpp`: RAN launched with ONE kernelParams pointer for the 64 B kernarg (`enqueue_v3`); harness path owns a private zeroed ERR/STEP page; device block built with nullptr per-launch pointers and `gpeers`; `sm_poison_v1` now returns the ERR word. Shared `host/sm_fusion_driver.cpp`: new ABI-3 entry points under `#if SM_ABI_VERSION >= 3` (the v1 set is compiled only for ABI < 3, so r17/r18 builds are unchanged): `sm_attach_v3(rank, comm, rx_win, rx_local, ctl_win, ctl_local, gpage_local, gpeers, gemm_hsaco, ran_hsaco, &ctx)` (gpeers NULL: the driver resolves the 3 peer ERR words with ccoGetPeerPtr(comm, gpage_local, p) and uploads a device-resident `SmGfPeers`), `sm_bind_new_v1`, `sm_launch_blk_v3(ctx, blk, A, W, strideA, Ascale, positions, slot, t_valid, call_id, stream)`, `sm_blk_free_v1`, `sm_free_v1`, `sm_info_v1`. No per-plan poison read in ABI 3.

## Checks that exist now
`tests/check_r19_static.py` (27 source-level assertions, all PASS: every flag release is inside `release_tagged`; no SM_C_POISON / per-launch SmDev reads; reasons < 0x100; SmRanArgsV3 layout; NaN/tag sites; driver exports). `check_directives.py` (LG-C18 checker) passes on all r19 sources and the shared driver.

## Unverified / deviations (report to the lead)
1. Not compiled: the largest risks are `__shared__` variables inside the now-`__device__` `ran_body`, the `set_err` CAS overloads on `uint32_t*`, and the B-WG restructure (x loads under `if (ok)`, NaN fill after).
2. ISA gates to run (E1/G-ISA): single `vmcnt(0)` entry round (`check_isa_single_wait`) with the predicated pad loads; `global_store ... sc0 sc1` for the tag store precedes `buffer_wbl2`/`s_waitcnt`/RMW in the same lane; the B-WG tag load is a system-scope load; no scratch; VGPR budget.
3. NO_GRIDREAD end-of-launch grid check (WG0) can only set ERR AFTER the launch's outputs were produced: a wrong-grid launch is NaN only from the NEXT launch on (r8 deviation, unchanged); a too-small grid still starves the B polls into 0x20.
4. A tag mismatch is detected per wave: waves that loaded the tag before the late store see a mismatch, others may not; their rows are NaN only for the observing waves (the sticky ERR word makes every later launch NaN, and the step's requests are aborted per I4).
5. `t_valid > T` is refused by the host (E_ARG); positions/slot_mapping must hold at least `t_valid` int64 and Ascale at least M floats.
6. `sm_attach_v3` requires `gpage_local` to be 64 B aligned and, when gpeers is NULL, to lie in a registered window so `ccoGetPeerPtr` resolves the peers.
## Test seam added after Evidence control (iv) (default 0, preprocessor-only: the code object is byte-identical when the macro is 0)
- `SM_TEST_DELAY_PUSH_DATA=<n>`: every wave of the push WGs and IK owners sleeps n x s_sleep(127) BEFORE issuing its push16 DATA stores (the flag release is not delayed). Usable alone; intended together with `SM_TEST_RX_BEFORE_FLAG=1` (needs `SM_RX_BYPASS=1`; default in r20/r21, explicit in r19) so that the pre-flag bypass loads observe stale/torn Rx. n=20 is about 80 us.

## Overhead round (R12-small-overhead.md F1/F2), A/B switches
- **SM_TAG_EARLY (default 1; 0 = previous order):** the releasing thread stores its destination tag(s) in the SAME batch as its push16 data stores (push WG: tid 0 for its destination; IK owner: tid 0 stores all 3 tags with its data; PUSH8/HALVES variant: tid 0 first touched destination, tid 256 second). The existing per-wave `vmcnt(0)` before the barrier retires them, so the later `fence(release)` has no remote store outstanding (C1). D-2 still holds: the SAME thread, issued in program order BEFORE its own fence (`release_tagged` is then just fence + vmcnt(0) + RMW). `SM_TEST_TAG_AFTER_RELEASE` requires `SM_TAG_EARLY=0` (#error otherwise).
- **SM_POLL_BATCH (default 1; 0 = previous loop):** `poll_range64` issues the flag load and the ERR load back-to-back (one wait; a compiler barrier keeps them together). ERR remains liveness-only: the flag value is still checked first, so a ready flag is never hidden by ERR.
- **New stamps (SM_STAMPS build):** 36 = release begin (push tid 0 / IK owner / variant), 38 = early tag issue, 39 = B poll start (existing 8 = flag seen, 26 = release done, 15/57 = poll iterations).
- Static checks re-run (`tests/check_r19_static.py` ALL PASS): the tag-before-own-fence assertion now reads "same thread, issued before its fence" (early sites are `if (tid == 0|256)` blocks in the data-store phase; the helper's own tag store remains only for `SM_TAG_EARLY=0` and the G10b seam). Not compiled; r21 is NOT changed in this round.
