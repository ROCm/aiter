# PR #7410：最新 main 对照下的 EP4 S1F T16384 优化

本轮只比较 V1 与 V3，取消 V2。当前正式默认已恢复原 S1F SiLU 舍入次序，Flash S1F 使用 chunk16；三轮交替测试的 median 为 V1 `1744.691219`、V3 `1604.979875` µs/layer，降时 `8.007798%`。三轮四 rank 的完整输出全部与同轮 V1 bit-identical。目标是完整八层 graph 降时超过 20%，目前尚未达到；其余明确标为单轮的结果用于候选筛选。

撤回前的 S1F SiLU FMA 配置三轮 median 为 `1601.414219` µs/layer，V1 为 `1747.273031` µs/layer，降低 `8.347797%`；只设置 pin，没有使用 tile、APRE 或 producer 调优 overrides。该数字不代表最终原舍入配置的成绩。保留原舍入次序的 chunk4/8/16 单轮分别为 `1609.108437`、`1604.961813`、`1604.498000` µs/layer，三项四卡完整输出均与 V1 bit-identical。

当前正式默认使用 G1 row-major input / APRE A2，G1 为 M256/N256/K256/w2x2/b3、prefetch0；G2 为 M256/N256/K256/w2x2/b4、四个 TDM owner waves。实验文件名 `kernel_g2_b4planarwpt4.py` 中的 planar 不是实际布局：该 G2 分支使用非 planar、非 interleaved LDS。V3 的 pin VGPR 保持开启。

## 测量与数值口径

计时沿用原 benchmark：每次 replay 完整八层，20 次 host wall-clock 样本；各 rank 取排序后的 `[10]` upper median，四 rank 平均后除以 8。这包含 RMSNorm/residual、replay 和 sync 开销。正式验收逐版本取三轮独立进程的 median；分项不相加充当总耗时。

所有版本复用相同的 quantized weights、input 和 routing，并保存 SHA256。FP32 reference 仅在输入、routing、层数及 reference source hash 完全相同的情况下复用；原 acceptance tolerance 保持不变。性能前后均检查全部 GPU，等待时每 6 秒复查；计时中不运行 GPU telemetry。

## 移植与适配

已移植 native compute、固定 operand/ring 地址、operand reuse、4×4 clustered persistent 及 compatible next-N 逻辑。CSV 仅加入源 E64/E65 T16384 的五条相关配置。S1F 动态下一项任务没有被假设为相邻 N。

已修复 APRE scale TDM 的 global/LDS majorness 不兼容、resident ring phase 的 constexpr 展开、短 M body 的 pinned scale slot，以及 claim SSA 在 M-tail 分支外使用的问题。APRE mode2 由 TDM 转换 FP4 A，scales 使用既有 row-major LDS lane addressing。

保留 dropped-route masking，使用已有 `Routing.topk_ids` 传递 source IDs。combine 的候选优化让对齐到单一 token 的 block 使用 uniform routing-ID 地址，累加次序和 NaN dropped-slot 处理保持不变。

APRE full-ring prefetch 的 deferred C 候选新增独立输出 staging，保留原重叠断言和退役协议，不以删除断言解决 LDS 重用冲突。G2 cluster 设置可以通过既有阶段 env `AITER_FLYDSL_MXFP4_CLUSTER_M1/N1/M2/N2` 单独调整。

最近新增候选包括 CM1/CN4 persistent GEMM2，以及 row-major G1 input / APRE A2 的独立布局。它们仍处于筛选，不能标为最终默认配置。row-major input 的前两次尝试触发 claim SSA dominance 编译错误（`v3_rminput_screen_0`、`v3_rminput_nopref_screen_0`）；已将对应 M-tail 路径的 claim 移到所有分支之前再验证。失败日志均保留，未用失败运行中的耗时。

新增的非 resident pin 候选将 C 放在 v64 起的区间，并将两个 operand slots 按实际 geometry 紧接在 C 后面。M256/2x2 的单 kernel VGPR 从 1024 降至 832；这只是资源变化，不代表耗时收益。clustered resident 的固定 ring 布局仍单独保留。

G1 的 M256/2x2 S1F 支持三或四个 input buffers，cache key 包含 buffer 数；三 buffer 路径也允许八 slot producer ring。H5120 combine 的 block 改为 320 threads，使一个 block 仅访问单个 token，两个 block 覆盖该 token 的 640 vector lanes。累加顺序、dropped-route mask 和 shared-add rounding 保留。
